یک مرکز، چندین هوش مصنوعی

مدل ابری یا محلی را انتخاب کنید و گفتگو را آغاز کنید.

پاسخ‌ها از طریق Worker عبور می‌کنند. کلیدهای API در کد مرورگر ذخیره نمی‌شوند.

مرکز مدل‌ها

مدل‌های ابری و محلی در یک فهرست. مدل محلی به اجرای Ollama یا LM Studio روی رایانه نیاز دارد.

افزودن مدل OpenAI-compatible

مدل محلی

برای اتصال از همین مرورگر، آدرس API محلی باید از مرورگر قابل دسترسی باشد و CORS فعال باشد.

تنظیمات و اتصال‌ها

نشانی Cloudflare Worker

نشانی Worker منتشرشده خود را وارد کنید؛ نمونه: https://your-worker.your-subdomain.workers.dev

کلیدهای API

کلیدها را در بخش Secrets داشبورد Cloudflare یا با دستور wrangler secret put تنظیم کنید. هرگز کلید را در GitHub، HTML یا LocalStorage قرار ندهید.

  • OPENAI_API_KEY
  • DEEPSEEK_API_KEY
  • GROQ_API_KEY
  • OPENROUTER_API_KEY
  • GEMINI_API_KEY

حریم خصوصی

تاریخچه گفتگو و آرشیوهای واردشده فقط در IndexedDB همین مرورگر نگهداری می‌شوند. پیام ارسالی برای دریافت پاسخ به سرویس انتخاب‌شده منتقل خواهد شد.

ورود آرشیو گفتگوها

فایل‌های JSON، TXT و Markdown پشتیبانی می‌شوند. در این نسخه، قالب‌های متنوع خروجی ChatGPT و Claude ممکن است به تطبیق قالب نیاز داشته باشند.
